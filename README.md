# Jurgis Sakalauskas — Portfolio

Personal portfolio website for a musician, sound designer and video game composer.

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS

## Features

- Game audio portfolio with Play Store links
- Live performances and discography
- Experimental music with SoundCloud players
- Contact section

## Getting Started

npm run dev
